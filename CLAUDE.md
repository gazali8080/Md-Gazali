# Md-Gazali

Motion-graphics skill setup for Claude Code. Project skills live in `.claude/skills/` and load in every Claude Code session on this repository.

## Skills

| Skill | Use when |
| --- | --- |
| `motion-design-rules` | Every motion graphic or video job: standing look and sound rules, plus the mandatory contact-sheet score-and-fix loop before showing or rendering. |
| `design-director` | Any visual output, including video and motion frames: the elevation review that runs before the user sees a result. |
| `remotion-best-practices` | Building, editing, previewing or rendering videos with Remotion: animation rules, timing, fonts, media, transitions. |
| `remotion-create` | Starting a new Remotion project or composition: scaffold, open Studio, then design and build. |
| `remotion-markup` | Writing Remotion React markup: compositions, Studio-editable structure, sequencing, transitions, effects, fonts, media, 3D, audio, parameterized videos. |
| `remotion-studio-render` | Previewing in Studio, rendering or exporting video and stills, upgrading Remotion. |
| `remotion-captions-maps-apps` | Captions and subtitles, map animations, Remotion apps or SaaS, Mediabunny metadata, Remotion docs search. |

## Standing rules

- Apply `motion-design-rules` and `design-director` on every motion or video job, together with whichever Remotion skill fits the current step.
- Do not render by default. Keep the Studio preview open while building and render only when the user asks for an export.
- For anything the skills do not cover, look up the current Remotion docs instead of relying on memory.
