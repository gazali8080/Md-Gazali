# Pivot table assignment (home appliances retailer)

- `input/` - question workbook (A) and answer workbook (B), downloaded from the shared Google Sheets links
- `output/Pivot_Table_Assignment_Solution.xlsx` - the workbook to submit: clean data plus one pivot table per question (Q1-Q11)
- `output/Pivot_Table_Assignment_Answers.docx` - written answers with tables, the Q10 chart and references
- `work/scripts/run_build.sh` - rebuilds the workbook (pandas ground truth -> LibreOffice pivots -> XML fixes -> verification)
- `work/scripts/gen_doc.py` - regenerates `output/assignment.md`, the source of the DOCX
